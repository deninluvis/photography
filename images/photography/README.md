# Photography folder

Drop your photos in here (`.jpg`, `.jpeg`, `.png`, `.webp`, or `.avif`), then commit and push to `main`. The site fetches this folder's contents live from GitHub, so no code changes or rebuilds are needed — the gallery updates automatically the next time someone loads the page.

- **Order:** images are sorted by filename. Prefix them with numbers to control the order, e.g. `01-golden-hour.jpg`, `02-night-market.jpg`.
- **Captions:** the caption shown in the gallery is generated from the filename — the number prefix is stripped and dashes/underscores become spaces, so `03-city-at-dusk.jpg` becomes "City At Dusk". Name your files accordingly.
- **This file** (and `.gitkeep`) won't show up in the gallery — only image files do.
