# Engineering design folder

Drop renders, CAD screenshots, or sketches in here (`.jpg`, `.jpeg`, `.png`, `.webp`, or `.avif`), then commit and push to `main`. The site fetches this folder's contents live from GitHub, so no code changes or rebuilds are needed — the gallery updates automatically the next time someone loads the page.

- **Order:** images are sorted by filename. Prefix them with numbers to control the order, e.g. `01-bracket-assembly.png`, `02-gearbox-render.png`.
- **Captions:** the caption shown in the gallery is generated from the filename — the number prefix is stripped and dashes/underscores become spaces, so `03-drone-frame-v2.png` becomes "Drone Frame V2". Name your files accordingly.
- **This file** (and `.gitkeep`) won't show up in the gallery — only image files do.
